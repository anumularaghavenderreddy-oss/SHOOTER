# 🚀 Space Shooter – Python

A simple **text-based Space Shooter game** built using basic Python. The game runs entirely in the terminal and does not require any external libraries.

## 📌 About the Project

This project is a beginner-friendly implementation of a Space Shooter game designed to practice fundamental Python programming concepts.

The player controls a spaceship and moves it left or right to align with an enemy. Once aligned, the player can fire a shot to destroy the enemy.

## ✨ Features

* 🚀 Move the spaceship left and right
* 🎯 Shoot at the enemy
* 💻 Terminal-based gameplay
* 📦 No external libraries required
* 🐍 Built using basic Python
* 👨‍💻 Beginner-friendly game logic

## 🎮 Controls

| Key | Action     |
| --- | ---------- |
| `a` | Move Left  |
| `d` | Move Right |
| `s` | Shoot      |
| `q` | Quit Game  |

## 🕹️ Game Symbols

| Symbol | Meaning             |
| ------ | ------------------- |
| `A`    | 🚀 Player Spaceship |
| `E`    | 👾 Enemy            |
| `.`    | Empty Space         |

## ▶️ How to Run

### 1. Save the Code

Save the Python code as:

```text
space_shooter.py
```

### 2. Open Terminal

Open a terminal in the folder containing the Python file.

### 3. Run the Game

```bash
python space_shooter.py
```

## 🎯 Example Gameplay

```text
A--E----

a=left d=right s=shoot q=quit : d

-A-E----

a=left d=right s=shoot q=quit : d

--AE----

a=left d=right s=shoot q=quit : s

Enemy Destroyed!
```

The player moves the spaceship toward the enemy and fires when both are aligned.

## 🧠 Concepts Used

This project uses basic Python programming concepts:

* **Variables** – Store game information such as player and enemy positions
* **While Loop** – Keeps the game running until the player quits or wins
* **Conditional Statements** – Handle player actions and game conditions
* **User Input** – Takes commands from the player using `input()`
* **Basic Game Logic** – Controls movement, shooting, and enemy destruction
